# HR Analytics Dashboard (SQL + Power BI)

## Overview
A mock HR analytics project analyzing employee headcount, attrition,
and salary trends using SQL Server for data modeling and Power BI
for visualization.

## Tools Used
- SQL Server / SSMS
- Power BI Desktop
- DAX

## What This Project Covers
- Relational schema design (Employees, Departments)
- SQL joins, GROUP BY, window functions
- DAX measures (attrition rate, average salary, headcount)
- Interactive Power BI dashboard: cards, bar chart, stacked column,
  retention funnel, trend line, multi-select slicers

## Key Insights
- Overall attrition rate: 15%
- Highest average salary: Engineering department
- Majority of attrition occurs in the 2+ year tenure bracket
